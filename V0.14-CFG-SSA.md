# V0.14: bounded CFG and path-sensitive SSA lowering

## Supported input

A restricted pseudo-C function with one `uint`/`uint32_t`/`unsigned int` argument and a uint32 return. The body may contain:

- `uint local;` and `uint local = expression;`
- `local = expression;`
- `if (unsigned_comparison) goto LABEL;`
- `goto LABEL;`
- `LABEL:`
- `return expression;`

Expressions support 32-bit unsigned `+ - * ^ & | << >>`, unary `~ - +`, and unsigned comparisons `== != < <= > >=`. Shift counts must be literal 0..31. Control flow must be acyclic and all reachable paths must return. The path budget defaults to 64, with a configurable maximum of 256.

## Lowering

`cfg_bridge.lower` splits the statement stream into basic blocks and computes successor indices. It symbolically executes each acyclic path, substitutes local definitions, gives path-local assignments globally unique SSA version names, and emits phi metadata for locals defined on every returning path plus a return phi. The executable candidate is a nested C conditional expression over the path guards.

This is a bounded path-expanded SSA-like representation, not a complete block-based SSA construction or general compiler frontend. Definitions are expression-substituted; loops, memory, pointers, side effects, signed comparisons, short-circuit boolean operators, and arbitrary C are unsupported.

## Verification

The candidate is compiled with GCC and compared to the original machine code using the existing x86-64 SysV pure uint32-to-uint32 SMT model. `UNSAT` is accepted as model-relative equivalence. `SAT` returns a concrete counterexample after native replay. `UNKNOWN` and unsupported instructions are not accepted. Native compilation and execution are not sandboxed; trusted local fixtures only.

The verifier's condition-code model now tracks ZF, CF, SF and OF for the supported `CMP`, `TEST`, `ADD`, `SUB`, logical operations, `INC`, `DEC` and `NEG` cases. It supports common unsigned conditions and the sign conditions required by compiler lowering of the high bit test. This does not imply complete x86 flag semantics.

## Local validation

- Regression suite: 85/85 tests passed.
- Ten manually authored branch patterns compiled by GCC and Clang: 20 binary fixtures.
- V0.13 typed straight-line parser: 0/20 accepted; V0.14 CFG bridge: 20/20 SMT `UNSAT` proofs.
- 44 enumerated return paths; maximum three paths per fixture.
- Cross-compiler native replay: 82,280 comparisons, zero mismatches.
- V0.14 pipeline time across 20 cases: about 1.10 seconds on the development machine, excluding cross-compiler replay.

These are authored development fixtures, not real Ghidra exports, firmware, or a blind independent corpus. Ghidra is still unavailable in the test environment. No automatic branch-condition repair is included in V0.14; incorrect branch logic is detected and a counterexample is reported.

## Reproduction

```sh
python -m unittest discover -v
python experiment_cfg.py
python cfg_bridge.py /path/to/trusted.so --pseudocode proposal.c --trusted
```
